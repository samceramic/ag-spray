農噴測量 安裝與雲端設定

把工具放上網址、安裝到 Android 和 iPhone 主畫面，並設定雲端備份。

存檔方式需要設定適合
手機本機（安裝成 App）放上網址後安裝一次每天使用，離線也能開啟
備份檔 → iCloud／Google 雲端硬碟／LINE不需要每週手動備份、換手機
Google 試算表同步管理員設定一次 Apps Script多位飛手的紀錄集中到一份試算表

一、把工具放上網址（GitHub Pages，免費）

手機直接開啟 .html 檔時，瀏覽器可能清除紀錄，也無法安裝或分享，所以要先放到一個 https 網址上。

  1. 到 github.com 註冊帳號（例如帳號叫 farmpilot）。
  2. 右上角「＋」→「New repository」，名稱填 ag-spray，選 Public，按「Create repository」。
  3. 在新頁面點「uploading an existing file」，把這個資料夾裡的所有檔案（先解壓縮，不要上傳 zip 本身）拖進去，按「Commit changes」。
  4. 到「Settings」→ 左側「Pages」→ Source 選「Deploy from a branch」，Branch 選 main、資料夾 / (root)，按「Save」。
  5. 約 1～2 分鐘後，網址會是 https://farmpilot.github.io/ag-spray/（換成你的帳號）。
紀錄只存在每支手機或管理員的 Google 試算表，不會上傳到 GitHub。別人知道網址只能使用工具，看不到你的資料。

之後若有新版本，只要在同一個 repository 再上傳新的 index.html 覆蓋即可，手機下次開啟會自動更新。

二、安裝到手機主畫面

Android

  1. 用 Chrome 開啟上面的網址。
  2. 點右上角雲朵圖示 →「安裝到主畫面」；或點 Chrome 的「⋮」→「安裝應用程式」。
  3. 從主畫面的「農噴測量」圖示開啟。

iPhone／iPad

  1. 一定要用 Safari 開啟網址。
  2. 點下方「分享」按鈕 →「加入主畫面」→「新增」。
  3. 之後都從主畫面的「農噴測量」圖示開啟。
iPhone 若沒有加入主畫面，Safari 可能在 7 天沒開啟後自動清除網頁資料。加入主畫面後就不受這個限制。

三、備份檔（不需設定）

  1. 點右側雲朵圖示 →「分享備份檔」。
  2. iPhone：選「儲存到檔案」→「iCloud 雲端硬碟」→ 選資料夾 →「儲存」。
  3. Android：選「雲端硬碟」上傳，或選「儲存到裝置」。也可以傳到自己的 LINE（Keep 筆記）。
  4. 換手機或資料遺失時：雲朵圖示 →「從備份檔還原」→ 選擇備份檔。

還原時會合併而不是覆蓋：同一筆紀錄以最後修改時間較新的為準，手機上較新的紀錄不會被舊備份蓋掉。超過 7 天沒備份時，雲朵圖示會出現橘點提醒。

四、Google 試算表同步（建議）

所有人的噴藥紀錄會自動寫入管理員的 Google 試算表，一筆一列，寫在「農噴紀錄」工作表，可以直接篩選、加總、列印。使用者不需要登入 Google，也不用加入測試使用者。

  1. 用管理員的 Gmail 到 Google 雲端硬碟 →「新增」→「Google 試算表」，命名例如「農噴作業紀錄」。
  2. 試算表上方選單「擴充功能」→「Apps Script」。
  3. 刪掉預設內容，貼上「農噴測量_雲端試算表_AppsScript.gs」的全部內容，把 your-name@gmail.com 改成管理員 Email →「儲存」。
  4. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→「部署」→ 依畫面授權（出現「Google 尚未驗證」點「進階」→「前往」）。
  5. 複製「網頁應用程式」網址（結尾 /exec）。
  6. App 用 admin 登入 →「帳號管理」→「Google 試算表同步」貼上網址 →「連結試算表」。有設定「同步到網站」會自動上傳設定；沒有的話請匯出 accounts.json 上傳。
  7. 同一個網址也能用於「管理員忘記密碼」：按「同一個網址也用於 Email 驗證」→「連結並啟用」。

更新 Apps Script 程式（網址不變）

  1. 打開試算表 →「擴充功能」→「Apps Script」，把內容全部換成新版「農噴測量_雲端試算表_AppsScript.gs」（記得再改一次 ADMIN_EMAIL）→「儲存」。
  2. 右上「部署」→「管理部署作業」→ 點現有部署右邊的鉛筆圖示 →「版本」選「新版本」→「部署」。
  3. 網址不變，App 不用重新設定。不要按「新增部署作業」，那會產生新網址。

紀錄寫在「農噴紀錄」工作表，一筆一列，共 72 欄，依「無人機噴藥試算」的順序分成作業資訊、田區與空域、噴灑參數、試算結果、配藥（藥劑 1～4 各一組欄位）、費用、紀錄，標題列以顏色區分。舊版的「噴藥紀錄」工作表會自動搬過來，並改名為「噴藥紀錄（舊版，可刪除）」。

同步時機：儲存或刪除紀錄後、開啟 App 時自動同步；沒有網路時會記下來，連上網路再補傳。也可以在雲朵圖示裡按「立即同步」。
一般帳號只會上傳、取回自己的紀錄；管理員會取回所有人的。換手機時登入同一個帳號，紀錄會自動回來。
請在 App 裡修改紀錄。直接改試算表儲存格不會傳回 App；最後一欄「資料(JSON)」是 App 用的，請勿修改或刪除。刪除的紀錄在試算表會標示「已刪除」。

天氣與風速自動帶入（中央氣象署）

  1. 到 opendata.cwa.gov.tw（中央氣象署開放資料平臺）→ 右上「登入/註冊」加入會員 → 登入後點「取得授權碼」，複製 CWA- 開頭的授權碼（免費）。
  2. App 用 admin 登入 →「帳號管理」→「中央氣象署天氣資料」貼上授權碼 →「儲存並測試」。
  3. 之後開啟「無人機噴藥試算」時，會自動帶入田區最近測站的天氣與風速（也可按「抓取氣象署資料」重新抓取），並顯示測站名稱、距離與觀測時間。數值可以自行修改。
儲存前會檢查：飛手、代噴單價、天氣、風速都要填寫。
天氣判斷：風速 3 m/s 以下「適合噴藥」，3～5 m/s「注意」（藥液易飄散，請降低飛行高度），超過 5 m/s 或下雨、雷雨「不建議噴藥」；位於紅區、黃區也會提醒。出現提醒時再按一次儲存即可確認儲存。

五、帳號與登入

身分可以使用
未登入（一般使用者）定位、新增目標田區（點選、數字加點、繞行記錄）、面積換算
一般帳號以上全部，加上無人機噴藥試算、配藥、空域判定、作業紀錄、匯出 Excel、雲端備份
管理員以上全部，加上新增、刪除帳號與重設密碼

新增或停用帳號

  1. 用管理員帳號登入 → 點「新增目標田區」圖示 →「帳號管理」（或雲朵圖示 →「開啟帳號管理」）。
  2. 輸入新帳號與姓名，按「自動產生」建立密碼，選權限。姓名會在該使用者登入後自動填入「飛手」欄位；既有帳號可在清單中按姓名旁的「填寫／修改」。
  3. 設定使用期間：點「7 天／14 天／30 天／90 天／1 年／不限」快速設定，或直接改開始日、到期日。開始日之前、到期日之後都無法登入。
  4. 按「新增帳號」→「複製帳號資訊」用 LINE 傳給飛手。
  5. 已建立的帳號可按「修改期間」延長或縮短，不必重設密碼；忘記密碼按「重設密碼」；要停用就按「刪除」。
  6. 改完後按「匯出 accounts.json」，到 GitHub 的 repository 點「Add file」→「Upload files」，上傳並取代原本的 accounts.json。
  7. 其他手機下次開啟（有網路時）就會套用：被刪除或到期的帳號會自動登出。

帳號自動同步到網站（建議設定）

設定後，在「帳號管理」做的任何變更會自動上傳到 https://samceramic.github.io/ag-spray/，約 1～2 分鐘後所有手機生效，不用再匯出、上傳。

  1. 電腦或手機登入 GitHub，打開 github.com/settings/personal-access-tokens/new（或在帳號管理按「到 GitHub 建立權杖」）。
  2. Token name 填「農噴測量帳號同步」，Expiration 選 1 年（到期前 GitHub 會寄信提醒）。
  3. Repository access 選「Only select repositories」→ 選 ag-spray。
  4. Permissions →「Repository permissions」→ Contents 選「Read and write」，其他維持不變 →「Generate token」。
  5. 複製產生的權杖（github_pat_ 開頭，只會顯示一次）。
  6. App 用 admin 登入 →「帳號管理」→「同步到網站」：儲存庫填 samceramic/ag-spray、分支 main、貼上權杖 →「儲存並測試連線」。
權杖只存在你這支手機，不會放到網站上。這個權杖只能修改 ag-spray 這一個儲存庫。手機遺失時，到 GitHub 的 Settings → Developer settings → Fine-grained tokens 把它刪除即可。

管理員忘記密碼（Email 驗證）

  1. 打開 script.google.com（用要收驗證碼的 Gmail 登入）→「新專案」。
  2. 刪掉預設內容，貼上「農噴測量_雲端試算表_AppsScript.gs」的全部內容（已包含 Email 驗證；若第四節已部署過，直接用同一個網址即可），把 your-name@gmail.com 改成你的 Email →「儲存」。
  3. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→「部署」→ 依畫面授權（出現「Google 尚未驗證」時點「進階」→「前往」）。
  4. 複製「網頁應用程式」網址（結尾是 /exec）。
  5. App 用 admin 登入 →「帳號管理」→「管理員忘記密碼」貼上網址 →「連結並啟用」。看到「已啟用：驗證碼會寄到 ...」就完成了。

之後管理員忘記密碼：登入畫面「忘記密碼」→ 輸入 admin →「寄送驗證碼」→ 到信箱收 6 位數驗證碼 → 輸入後設定新密碼（至少 10 個字元、英數混合）→ 自動登入。有設定「同步到網站」時，新密碼會自動上傳。

驗證碼 10 分鐘有效、每組最多錯 5 次、每天最多寄 10 次，而且只會寄到程式裡設定的 Email。一般使用者忘記密碼仍是傳訊息給管理員重設。

忘記密碼、申請新帳號

  1. 管理員先到「帳號管理」→「管理員聯絡方式」，填顯示名稱、LINE ID、手機或 Email →「儲存聯絡方式」→ 匯出並上傳 accounts.json。
  2. 使用者在登入畫面點「忘記密碼」或「申請新帳號」，填帳號、姓名、電話，按「用 LINE 傳給管理員」（或簡訊、Email），在 LINE 選管理員的聊天室送出。
  3. 管理員收到後：忘記密碼 → 在帳號清單按「重設密碼」；申請帳號 → 用「新增帳號」建立並設定使用期間。再按「複製帳號資訊」傳回給使用者，最後匯出並上傳 accounts.json。

聯絡方式會放在公開的 accounts.json，請只填可以公開的電話或 Email。帳號可使用中文，例如「使用者04」。

安全性說明
進階功能的程式已加密，沒有正確帳號密碼就無法解開，即使懂網頁的人查看原始碼也拿不到。
限制：工具沒有伺服器，所以帳號停用要等那支手機下次連網開啟才生效；離線期間仍可使用。若懷疑曾登入過的人外流了內容，可請我用新的金鑰重新產生一版並重設所有帳號。
帳號密碼清單不要上傳到 GitHub。 管理員密碼請妥善保管，日後更新版本時需要用它。

常見問題

  • 沒有網路時可以用嗎？ 安裝後可離線開啟、計算與儲存紀錄；衛星底圖與雲端同步需要網路。
  • 換新手機怎麼辦？ 舊手機先備份或同步，新手機安裝後「從備份檔還原」或「立即同步」。
  • 刪除 App 會怎樣？ 手機上的紀錄會一起刪除，請先確認已備份或同步。
